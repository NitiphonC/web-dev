งานที่ทำแล้วทักษะที่ได้ใช้ตอนสอบยังไง
โจทย์แบบฝึกหัด: Book Catalog API
ยังไม่ต่อ DB — จำลองข้อมูล		 REST 5 endpoint, status 200 / 201 / 404, CRUD พื้นฐาน ใช้เป็นโครง route ทั้งหมด — ในห้องสอบเปลี่ยนจาก array เป็น DB
สร้าง api Book, Review เลือก Express / Fastify / NestJS + ออกแบบ 2 ตารางที่มี relation ใกล้ข้อสอบที่สุด — books 1:N reviews คือ pattern เดียวกับ categories 1:N books
สร้าง next.js เชื่อมกับ backend CRUD ผ่าน UI + อัปโหลดไฟล์ ถ้าข้อสอบให้ HTML/CSS มา = เหลือแค่ JS เหมือนงานนี้
สร้าง Dockerfile + Docker Compose base image, volume, port mapping ถ้าโจทย์ให้รันผ่าน docker compose up
Workshop 1–2 (Mermaid) Flowchart + diagram สถาปัตยกรรม 3 tiers ข้อเขียนเชิงอธิบาย / วางระบบ
สไลด์: Node.js, RESTful & GraphQL, Next.js, Client-Side Overview ทฤษฎี คำศัพท์ และ comparison ข้อกา / ถูก–ผิด

สเปกงาน Book Catalog API (จำให้แม่น)

Data model

  • id Number
  • title String
  • author String
  • publishedYear Number
  • isAvailable Boolean

Endpoints

  • GET /books , GET /books/:id
  • POST /books
  • PUT /books/:id
  • DELETE /books/:id

Status ที่ต้องตอบ

  • 200 OK อ่าน / แก้ไข / ลบสำเร็จ
  • 201 Created สร้างใหม่สำเร็จ
  • 404 Not Found ไม่พบ id

งาน Book Catalog API ไม่ต้องใช้ฐานข้อมูล (จำลอง array) แต่ข้อสอบปฏิบัติเน้น 2 ตาราง + upload → เอาโครง route จากงานนี้ แล้วเปลี่ยนที่เก็บข้อมูลเป็น SQLite หรือ Prisma

แผนเวลา 4 ชั่วโมง

เป้าหมาย: ได้ระบบที่รันได้ก่อน แล้วค่อยเก็บรายละเอียด

  1. 0:00 – 0:20
    Clone + ตั้งโปรเจกต์

    clone repo, npm i, รันให้ขึ้น ดูว่า DB/พอร์ตอะไร แล้วจด schema ที่ให้มา

  2. 0:20 – 1:00
    ออกแบบ 2 ตาราง + สร้าง DB

    ตารางหลัก 1 + ตารางลูก 1 (มี FK) เขียน CREATE TABLE + seed ข้อมูล 3–5 แถว

  3. 1:00 – 2:20
    Backend CRUD ให้ครบ

    GET list / GET id / POST / PUT / DELETE — ทำตารางแรกให้เสร็จก่อน แล้ว copy มาดัดแปลง

  4. 2:20 – 2:50
    อัปโหลดไฟล์

    multer + static /uploads + FormData ฝั่งหน้าเว็บ

  5. 2:50 – 3:30
    Frontend JS

    ตาราง + ฟอร์ม + ปุ่มลบ + preview รูป

  6. 3:30 – 4:00
    เก็บงาน + กันพัง

    validate, error message, ทดสอบทุกปุ่ม, ข้อกา

Checklist ก่อนลงมือ

ติ๊กแล้วระบบจะจำไว้ในเครื่องคุณ

กติกาและความเสี่ยง

ตอนที่ 2 เปิดอินเทอร์เน็ตได้ แต่ห้ามใช้ AI — รวมถึงเว็บแชต AI, extension ที่เป็น AI, การถาม AI ผ่านช่องทางใดก็ตาม
  • ระบบเก็บ log การเข้าถึงอินเทอร์เน็ตและบันทึกหน้าจอตลอดเวลาสอบ
  • ทุจริต → ตกทุกวิชา (F) ไม่ใช่แค่วิชานี้
  • อนุญาต: เปิด docs, MDN, Stack Overflow, ค้น syntax — แต่ต้องเข้าใจและพิมพ์เอง
  • โค้ดที่เคยส่งการบ้านใช้ดู/ปรับได้ — เตรียมให้พร้อมก่อนเข้าห้อง
  • อย่าเปิดแท็บค้างที่ดูเหมือนพึ่งพาเครื่องมือต้องห้าม

เตรียมก่อนสอบ (ทำวันนี้)

  1. รันโปรเจกต์ตัวอย่างนี้ให้ผ่าน 1 รอบ → ดูว่าแต่ละไฟล์ทำอะไร
  2. ลบ public/app.js แล้วเขียนใหม่จาก cheat sheet ให้ได้ใน 30 นาที
  3. จำสูตร multer + FormData ให้ขึ้นใจ
  4. ลอง npx @openapitools/openapi-generator-cli generate กับ openapi.yaml ในโปรเจกต์นี้
  5. ซ้อมข้อกา 45 ข้อในหน้า แนวข้อสอบ ให้ได้ ≥ 80%
